# 全国+国际马拉松赛事追踪网站 设计文档

日期：2026-08-21
状态：已确认

## 背景与目标

参照 mlszz.com.cn（江浙沪马拉松追踪站），构建一个覆盖**全国田协认证赛事 + 国际重要赛事**的马拉松赛事追踪网站。集中展示比赛时间、报名窗口、竞赛项目和官方报名入口。

## 收录范围

- **国内**：中国田协全部认证赛事（A 类 + B 类，约 300+ 场/年）。基础名单来自田协官网历年赛事记录的抓取与 AI 清洗。
- **国际**：世界马拉松六大满贯（东京、波士顿、伦敦、柏林、芝加哥、纽约）+ 世界田联白金标赛事，约 20 场。名单预置 + 千问核对补全。

## 总体架构

```
中国田协官网 ──抓取清洗──> data/races.json（仓库内数据源）
                              │
GitHub Actions 每日定时 ──> 千问API联网查询赛事进展 ──> 更新JSON并提交
                                                        │
                              Vercel 自动部署 <──────────┘
```

- Next.js 15（App Router）+ Tailwind CSS
- 无 DB、无后端接口，赛事数据为仓库 `data/` 目录下的 JSON 文件
- GitHub Actions 定时执行更新脚本并提交 JSON，Vercel 监听仓库自动部署
- 部署：Vercel 免费额度 + 阿里云域名（用户尚未注册账号，配置文件先行准备，部署时逐步指引）

## 数据模型（每条赛事记录）

| 字段 | 说明 |
|---|---|
| id / name / shortName | 唯一标识、全称、简称（如"北马"） |
| country / province / city | 国家；国内赛事含省份城市 |
| raceDate / location | 开跑日期、起终点/比赛地点 |
| regStart / regEnd | 报名起止时间（可空，"暂未公布"） |
| regStatus | pending（筹备中）/ open（报名中）/ drawing（抽签中）/ closed（已截止）/ finished（已结束） |
| lotteryDate | 抽签时间（需抽签赛事） |
| scale | 参赛规模 |
| events | 竞赛项目数组（全马/半马/女子马等） |
| fee | 报名费用说明 |
| category | A / B / platinum（白金标）/ gold（金标）/ major（六大满贯） |
| needLottery | 是否需抽签 |
| officialSite | 官网/报名链接（可空） |
| updatedAt | 该条记录数据更新时间戳 |

## 数据管道（scripts/）

1. `init-domestic`：抓取中国田协官网 A/B 类赛事名录，AI 清洗去重，生成国内基础名单。
2. `init-international`：预置大满贯+白金标名单，千问联网核对补全字段。
3. `update-status`：Actions 每日执行。调用阿里云百炼千问 API（联网搜索）查询赛事报名/抽签进展，写回 JSON。

### 更新频率与成本控制

- 近 90 天内赛事 + 报名中赛事 → 每日查询
- 90 天外赛事 → 每周查询一次
- 已结束赛事 → 不再查询
- LLM 单场查询失败 → 保留旧数据，标记更新失败，不阻断整体；Actions 失败不提交坏数据
- 脚本支持本地 dry-run 模式（只输出预览不写文件/不提交）

## 前端页面（单页）

- 头部统计：报名中 / 抽签中 / 备赛倒计时 数量 + 数据更新时间
- 两大板块切换：🇨🇳 全国赛事 / 🌍 国际赛事
- 筛选器：省份（国内）或大洲（国际）、报名状态、项目类型（全马/半马）、关键词搜索、快捷筛选（未结束/已结束）
- 赛事卡片：名称 + 认证徽章 + 状态徽章 + 比赛时间/地点/报名窗口/规模/项目/费用/抽签 + 官网链接
- 排序：报名中 → 即将开启 → 备赛倒计时 → 已结束；截止临近赛事置顶高亮
- 首期不做独立详情页，卡片内信息完整呈现
